# Fonts

The interface typefaces. Each keeps its own licence; none is covered by Madloop's MIT licence.

| File | Typeface | Licence |
| --- | --- | --- |
| `IBMPlexMono-Regular/Medium/SemiBold.woff2` | IBM Plex Mono, by IBM. Unmodified, from `@ibm/plex-mono` 2.5.0 | SIL Open Font License 1.1, see `IBMPlexMono-LICENSE.txt` |
| `Geist-Variable-Latin.woff2` | Geist, by Vercel. Latin subset | SIL Open Font License 1.1, see `Geist-LICENSE.txt` |
| `DSEG7Classic-BoldItalic.woff2` | DSEG7 Classic, by Keshikan. Unmodified, from `dseg` 0.46.0 | SIL Open Font License 1.1, see `DSEG-LICENSE.txt` |
| `visitor2.ttf` | Visitor TT2 BRK 3.22, by Brian Kent (Ænigma Fonts). Unmodified | Freeware, see `Visitor-README.txt` |

IBM Plex and DSEG have Reserved Font Names, so they are shipped exactly as released. Geist has
none, so a Latin-only cut is fine. Visitor's author asks that his readme stays with the font and
that the font file is not altered.
